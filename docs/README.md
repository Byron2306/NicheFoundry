# NicheFoundry GitHub Pages site

This folder contains the self-contained static marketing site for NicheFoundry.

## Preview locally

```bash
cd docs
python -m http.server 8000
```

Open `http://127.0.0.1:8000`.

## Publish

After this branch is merged:

1. Open the repository **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and the `/docs` folder.
5. Save.

Expected project URL:

```text
https://byron2306.github.io/NicheFoundry/
```
