# Optional Piper voice models

The Phase 1 source release does not bundle large `.onnx` models or a Python virtual environment.

Use the supplied installer scripts and optional voice pack:

```bash
./scripts/install_piper.sh
./scripts/install_voice_pack.sh /path/to/NicheFoundry_Phase0_Voice_Pack.zip
```

The Phase 0 voice pack remains compatible because Phase 1 does not change the local narration model format.
